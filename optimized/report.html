几乎全是头像。原图 1505×1506、1,288 KB，但界面上只显示 32 / 38 / 68 px 三个尺寸——一个文件就吃掉首屏 95% 的流量。现在按头部重新裁切，输出 192px WebP 12.2 KB、96px WebP 4.8 KB。

做了什么 性能

  1. 头像按显示尺寸重出

    1505² 的 PNG 换成裁好构图的 WebP，CSS 里 width:220%; left:-60% 的硬裁切也一并去掉。

  2. 消灭阻塞请求

    27.9 KB 样式内联进 <head>，首屏不再等一次关键路径往返；三个 JS 合成一个并改为 defer。

  3. 首帧前定主题和高度

    data-theme 与 --app-height 由 head 内同步脚本先写死，深色模式不再白闪，移动端也不会因地址栏跳动。

  4. WebGL 延后 + 降频

    光场在 load 之后用 requestIdleCallback 加载，0.65×DPR、30fps、页面隐藏即停帧，不抢首屏 CPU 和 GPU。

  5. 流式输出按帧合并

    原来每来一个 token 就重写一次 innerHTML；现在一帧合并成一次 textContent，结束再渲染 HTML。

  6. 滚动不再抢控制权

    只在用户本来贴底时自动跟随，往上翻历史不会被打断。

  7. 历史对话批量插入 + 长列表跳过渲染

    DocumentFragment 一次性替换；超过 24 条才启用 content-visibility，避免影响短对话的布局精度。

  8. 服务端预压缩与缓存

    build 阶段生成 .br/.gz 直出，按类型下发 Cache-Control，支持 304。原版是 max-age=0，每次都要重下。

  9. Service Worker

    导航 stale-while-revalidate、静态 cache-first、/api/ 完全绕过。二次打开 38 ms，断网也能出界面。

做了什么 视觉

玻璃不是一层 backdrop-filter 能撑起来的。白底上尤其难——白玻璃压在白背景上，只剩阴影可以看。所以拆成四层叠：

1
冷白填充rgb(250 252 255)，比纯白低半度。这是白底上玻璃能被"看见"的唯一依据。
2
1px 发丝线白底上白色描边等于没有，所以用 rgba(15,20,32,.075) 的冷灰细线；深色下换成 15% 白。细，但要利。
3
2px 折射环feTurbulence + feDisplacementMap 把边缘背后的画面做位移。只做"边缘一点点弯"，不做粗边框——玻璃的厚度感来自这里，但宽度必须克制。
4
液面光泽跟随指针的径向高光，用 CSS 变量 + requestAnimationFrame 节流，只在精确指针设备上启用。

背景是纯白 #ffffff。底下有一层原生 WebGL 光场（4 个缓慢漂移的光池），浅色下只留 5.5% 着色——大面积实测仍在 249–251，肉眼就是白，但玻璃边缘有了可以折射的东西。

没有引 Three.js。这里只需要一层柔光，three.js 光核心就 150 KB+，比整个优化后的首屏还大。用原生 WebGL 画一个全屏三角，3.8 KB 就够。

部署 原有文件一律不动，可随时回滚

# 1. 先备份线上 public
ssh root@8.134.141.217 "cp -r /path/ali-deploy/public /path/ali-deploy/public.bak.$(date +%F)"

# 2. 传产物（只覆盖 public 和 server.js）
scp -r optimized/public/* root@8.134.141.217:/path/ali-deploy/public/
scp optimized/server.js root@8.134.141.217:/path/ali-deploy/server.js

# 3. 重启
ssh root@8.134.141.217 "cd /path/ali-deploy && pm2 restart all"
回滚：把 public.bak.* 换回去重启即可。原版文件在仓库里一直是原样，没有被动过。
发版提醒：改了前端后把 sw.js 里的 VERSION 改成 qisao-v2，否则老用户可能还读缓存。

顺带发现 建议一并处理

旧版 deploy/static/js/app.js 把 SILICONFLOW_API_KEY 直接写在前端，任何人查看源码都能拿到并盗刷。优化版走 /api/ 代理，Key 只在服务端——如果线上还有直调版本在跑，建议换掉这把 Key。
