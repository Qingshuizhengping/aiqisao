# AI七嫂·员工专属版

面向小团队的独立聊天与项目空间，支持桌面、手机浏览器及 PWA。运行于 Node.js 24 LTS、Express 和 SQLite WAL，单实例部署。内部版独立保存账户、会话、聊天、记忆、素材和审计数据，代码目录自带全部前端依赖，可单独 clone 后构建。

助手名称为“AI七嫂·员工专属版”，头像和安装图标复用原 AI 七嫂的蓝色人物形象。所有角色均使用账号和密码登录，不再要求动态验证码。密码至少 6 个字符，可以为纯数字；已有密码保持有效。

默认执行找回的[美业七嫂视角人格 skill](skills/meiye-qi-sao-perspective/SKILL.md)：5 个心智模型、9 条决策启发式及[完整表达 DNA](skills/meiye-qi-sao-perspective/references/research/03-expression-dna.md)。原版主文件和 6 份研究资料保持不变，仅存于服务端；内部适配在 `lib/persona.js` 中，普通聊天与严格资料回答草稿共用。回答角色直接采用七嫂的表达，普通中文总结执行短句对仗、先抓重点再拆动作；风格不达标时最多重写一次草稿，之后仍须通过事实、数值与语义核验。问候和自我介绍使用受控的人格文案。人格不冒充创始人，不将示例数字、产品用量或收益承诺作为业务事实，也不新增联网工具。核验、标准事实提取和自动记忆提取维持各自规则；关键值和原文引用不经人格改写。

普通聊天和复制只显示自然正文，不显示核验状态、来源卡片或系统追加的引用编号。后台引用元数据、来源版本与权限校验继续保留，审计入口查看原始记录；用户输入、原文润色、代码和业务方括号不按引用编号删除。进度只显示“正在整理思路…”，核验前的模型草稿仍不对外发布。

核心模块的职责、异步操作归属与资料任务边界见 [ARCHITECTURE.md](ARCHITECTURE.md)。已审核共享资料归项目使用，原上传者停用或退出后仍可由当前项目管理员维护和重建索引。

外观采用用户参考工作台的中性灰白与炭灰玻璃风格，详见 [DESIGN.md](DESIGN.md)。支持浅色、深色和手机抽屉导航。

部署入口为 `https://8.134.141.217:6069`，通过独立 Nginx HTTPS 端口代理到服务器 loopback，员工必须登录后才能访问工作空间。源代码位于 GitHub 的 `internal/` 目录，配置、模型密钥、数据库和备份不进入 Git。当前状态、验证证据及限制见 [VERIFICATION.md](VERIFICATION.md)。

## 功能与权限

- 成员维护个人聊天、个人记忆、资料文件、所属项目中的自己的聊天和项目私有记忆。
- 项目管理包括名称、背景、工作指令、成员角色和归档。项目管理员可以只读查看本项目成员的原始聊天，审核共享记忆候选；不能进入其他成员的私人记忆库。
- 系统管理员通过独立只读审计入口查看全部项目、个人聊天、记忆和资料文件。审计不会扩展日常聊天的检索权限，也不能替其他用户发送、修改或删除聊天。
- 新账号首次登录需要修改初始密码。账号停用、角色变化和项目撤权立即按数据库当前权限重新校验。

登录及工作空间会明确告知成员管理员的可见范围。敏感读取和管理操作写入审计记录，审计日志不保存正文、密码或模型密钥。

## 控制面板

系统管理员可从侧栏的“控制面板”或 `https://8.134.141.217:6069/admin` 进入管理界面：查看账号统计、按姓名/角色/状态筛选，新增账号、编辑名称、调整系统角色、重置临时密码、停用与删除账号，并集中分配每个项目的成员或管理员权限。普通成员无权进入该入口。

系统角色与项目角色分别授权；系统管理员不会因此自动加入项目或将他人的私人资料用于自己的日常聊天。当前管理员不能停用、删除或撤销自己的系统管理身份；有效项目至少保留一位有效管理员。归档项目权限只读。

删除账号会立即停止登录、撤销现有会话，并放入回收站。原聊天、记忆、文件和审计记录保留；恢复后保持停用，需要管理员核对权限并明确启用。旧 TOTP 绑定不再影响登录，旧绑定接口已退役；不会重置现有密码或批量修改历史内容。

## 回答模式

回答模式由**一个**环境变量决定：`INTERNAL_GROUNDING_MODE`。

- `free`（默认）：开放回答。照常检索记忆与资料并注入上下文，但检索为空**不再阻断**回答，模型用自己的常识和推理作答；有资料时以资料为准并注明文件名，没有资料时不得说“暂无依据”“无法回答”这类兜底话术，也不得虚构文件名、条目或引用。价格、政策、名额、库存、活动期限这类会变化的信息不给确定值，必须提示需确认最新信息。
- `strict`：回滚开关。恢复 v1 的四阶段核验（检索 → 草稿 → 核验 → 发布），没有已确认依据时回答“暂时无法核实”。四阶段代码完整保留，只由这个开关决定是否启用。

`/api/health` 的 `grounding.mode` 反映真实模式，控制面板的“设置”区只读展示。判定逻辑不看是否注入模型供应商——测试与生产走同一套分支，避免“用例全绿但走错分支”。

依据角标：普通成员在回答下方看到“参考 N 条资料”（展开可看文件名/记忆条目）与“来自网络 N 条”（附标题与链接）；没有依据时不显示角标，也不会写“无依据”。

## 素材生成

侧栏“素材生成”打开面板，输入画面描述、选五档模板与六档尺寸后生成。上游为腾讯 TokenHub 混元生图（`hy-image-v3.5-preview`，Bearer 鉴权，同步返回，超时 150 秒）。

- **六档尺寸，不做 4K**：1:1（2048×2048）、3:4（1536×2048）、4:3（2048×1536）、9:16（1152×2048）、16:9（2048×1152）、自动（不传尺寸，由模型决定构图）。面积上限 2048×2048。
- **异步任务**：提交即返回任务号，前端每 2 秒轮询；关闭面板、刷新页面都不中断任务，重开面板会从历史里恢复“生成中”并继续轮询。
- **仅本人可见**：每个查询都按 `user_id` 过滤，跨账号访问返回 404；没有“看他人素材”的接口。
- **图片不进加密备份**：文件落在 `INTERNAL_DATA_DIRECTORY/images/<yyyyMM>/`，不在 `dist/` 下（构建不会删），也不在 SQLite 里，因此**不受 `npm run backup` 与加密离机导出保护**。详见 [DEPLOYMENT.md](DEPLOYMENT.md)。
- **失败分级**：额度未开通 / 鉴权失败 / 内容审核 / 上游繁忙 / 上游异常各有独立错误码与文案；“已提交但结果未知”（超时、连接中断、2xx 但解析不出图）单独提示“可能已生成并计费，先看历史”，**不自动重试**。
- **限流**：每账号每分钟 5 张、每小时 30 张；全局并发 2，排队上限 8。未配置密钥时功能不可用（`/api/images/options` 返回 `enabled:false`，提交返回 503 `IMAGE_NOT_CONFIGURED`）。

## 共享项目

- 项目管理员在“项目信息”里打开“共享给团队”；只有被标记共享的项目才会出现在系统管理员的账号授权清单里。**共享标记只是“可被授权”的资格，本身不扩大任何人的可见性**——可见性依旧只看 `project_members`。
- 系统管理员在控制面板**新建或编辑账号**时勾选该账号加入哪些共享项目，保存即生效。授予的角色固定为项目成员；已在该项目是管理员的不会被降级，撤销也不会删除管理员关系。
- 被授权账号在侧栏“共享项目”里看到这些项目，可正常聊天、查看自己的历史；**项目设置、成员与归档只有项目管理员能改**，成员视角不渲染这些入口，直接调用接口返回 403。
- 撤销勾选立即失效：权限实时查库，正在生成的回答在 1 秒内停止并提示“账号或项目权限变化，生成已停止”，已产出的内容保留。归档项目对成员只读。

## 三种记忆

生产聊天使用“严格依据资料＋重要事实先确认”。请从记忆库的“事实与确认”确认来源，并核对价格、用量和参数等标准事实；历史记忆不会自动成为权威依据。回答先核验再展示，缺失、冲突或校验故障会明确提示。操作、接口与边界见 [GROUNDING.md](GROUNDING.md)。

`personal` 保存跨项目偏好和长期背景；`project_private` 仅在当前项目为本人使用；`project_shared` 由项目管理员批准后供项目成员使用。模型仅提出共享候选，不能自行批准。记忆库支持搜索、编辑、停用、删除、来源和版本信息。冲突不会静默覆盖已有记忆，已删除或编辑的条目不会被旧任务重新写回。

自动整理默认开启，在回答完整保存后异步执行，要求提取项附带本轮用户原文证据。输入区不再显示“写入记忆”开关，新讨论默认开启，旧的可编辑讨论在发送时也会启用。账号设置中主动关闭自动整理时，仅停止新增提取；已确认资料仍可用于回答。索引失败保留解析文字供查看与重试；严格聊天检索故障时停止事实生成，显示暂时无法核实。

## 资料文件

记忆库的“资料文件”页支持多文件上传、解析进度、文字预览、原文件下载、重试和删除。支持 TXT、Markdown（.md）、CSV、JSON、可复制文字的 PDF、Word（.docx）和 Excel（.xlsx）。每个文件最多 10 MB、20 万字符；每个资料范围最多 40 个文件，每人总原文件量最多 200 MB。PDF 最多 200 页。图片、扫描件 OCR、旧版 .doc/.xls 和加密 PDF 暂不支持。

资料采用相同的个人、项目内个人、项目共享范围。个人资料可在本人的讨论中检索；项目资料只用于所属项目。普通成员上传共享资料后先作为候选，仅上传者和项目管理员可查看，审核通过后才供项目其他成员检索。归档项目只读。系统管理员通过专用审计入口查看，不会把他人的资料加入自己的日常聊天上下文。

服务器保留原文件，在有时间和资源上限的独立工作线程中解析文本，再分段建立语义索引。处理队列持久化，离开页面不会取消处理；重启前已在处理的任务标为中断并提供重试，尚未开始的任务继续执行。语义索引失败时保留关键词检索。回答显示检索到的文件来源，可打开纯文字预览；不会把文件内的文字作为系统指令执行。删除文件后停止后续检索并清除原文件与解析内容，已有聊天记录不因此删除。

原文件、提取文字、分段和索引均保存在独立 SQLite 数据库，纳入现有一致性备份和加密导出。含密码、密钥或验证码的文件会被阻止进入索引。详细设计见 [KNOWLEDGE.md](KNOWLEDGE.md)。

默认聊天和记忆整理模型为 `zai-org/GLM-5.3-Flash`，嵌入为 `BAAI/bge-m3`，通过 SiliconFlow HTTPS 接口处理必要的文本。资料解析在服务器本地进行，建立索引时会将提取的文字分段发送给配置的嵌入服务，回答时将相关片段发送给聊天模型。组织应向员工说明这一外部处理过程。模型不接收原文件或整个数据库。本版本包含素材生成（混元生图，需配置密钥）与联网搜索适配层（默认未启用），不含任务看板或 APK。

## 本地运行

在此目录执行 `npm ci`，复制 `.env.example` 为 `.env` 并设置独立的 32 字节 base64 加密密钥、初始管理员密码、模型密钥。本机开发可设置 `INTERNAL_ORIGIN=http://127.0.0.1:3001` 并使用非 production 环境。生产必须使用 HTTPS，密钥不能提交 Git。

```sh
npm ci
npm test
npm run build
npm start
```

构建所需的 Markdown 渲染器（`src/vendor/marked-18.0.9.mjs`）、站点样式快照与图标都已内置在本目录，`internal/` 单独拷贝出来即可 `npm ci && npm run build`，不依赖任何兄弟目录。首次登录后按界面设置自己的密码即可进入工作空间，获得管理权限也不再要求绑定验证器。

聊天任务在服务器持久化，SSE 仅订阅结果；切到后台或断开页面不会取消生成。重新打开会同步同一任务，明确点击停止才终止。服务重启会将已执行任务标为中断，避免自动重复计费；尚未执行的排队任务恢复执行。

PWA 仅缓存静态外壳，API 使用网络且不缓存。原始聊天和记忆不写入浏览器本地持久存储；草稿仅按用户和会话存入 sessionStorage，退出或换号清除。离线时不能读取或发送内部聊天。

## 验证与部署

`npm test` 使用合成数据及模拟模型，覆盖密码登录、CSRF、权限隔离、账号删除恢复、只读审计、任务幂等、断线恢复、记忆来源/冲突/删除保护及加密备份。真实供应商验证须单独授权且不可与自动化测试混用。

部署、HTTPS、最小权限、每日 14 天本地备份、AES-GCM 离机副本、恢复演练和回滚见 [DEPLOYMENT.md](DEPLOYMENT.md)。备份脚本不会将同一主机的其他目录自动认定为离机保护。
